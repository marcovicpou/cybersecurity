# Dream Last — teste local no XAMPP

O projeto completo está em [dreamlast_portfolio_completo](dreamlast_portfolio_completo/). A página original de cybersecurity foi mantida.

## Baixar o pacote

[Baixar ZIP para XAMPP](https://github.com/marcovicpou/cybersecurity/raw/refs/heads/dreamlast-xampp-redesign/downloads/DreamLast-XAMPP-Teste.zip)

O arquivo também está na pasta downloads. Na visualização do GitHub, use o botão de download do arquivo.

## Executar

1. Extraia o ZIP.
2. Copie a pasta dreamlast_portfolio_completo para C:\xampp\htdocs\.
3. Inicie Apache no painel XAMPP.
4. Abra http://localhost/dreamlast_portfolio_completo/ no navegador do seu computador.

Depois de copiar a pasta, você também pode executar ABRIR-TESTE-XAMPP.bat para abrir o painel e o navegador. O atalho considera Apache na porta 80.

Para testar PDV, ERP e CRM, inicie MySQL e siga [as instruções de banco](dreamlast_portfolio_completo/README.md). O portfólio e seus três cases não precisam de banco.

PHP 8.1 ou superior recomendado, com pdo_mysql e mbstring. Assets e fonte estão incluídos; não é necessário npm ou build.

Os checks estão documentados em [VALIDACAO.md](dreamlast_portfolio_completo/docs/VALIDACAO.md). A logo oficial não foi anexada; o monograma DL é provisório.
