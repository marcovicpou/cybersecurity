# Entrega de teste

Esta rodada: publicar código e ZIP no repositório autorizado, com README para XAMPP. Não publicar serviço na internet nem submeter lojas.

Próxima validação de produto: teste moderado com 3–5 voluntários autorizados, pedindo explorar prato, identificar total, confirmar pedido e excluir dados. Esta meta não é uma contagem de usuários existentes. Registrar dificuldades reais e só então ordenar melhorias.

Não há analytics, waitlist, rastreamento de erro externo ou comunidades contatadas. Logs locais não registram endereço/observações. Screenshots do próprio protótipo acompanham a documentação. Requisitos de stores e URLs públicas de privacidade/suporte deverão ser verificados se publicação nativa for solicitada.
